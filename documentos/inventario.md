# Inventário de materiais

| Material | Destino | Situação |
| --- | --- | --- |
| Prancha original de identidade | assets/pranchas/ | Pendente: anexo não retornado |
| Logo original aprovado e editável | logos/originais/ | Pendente: anexo não retornado |
| Exportações do logo | logos/exportados/ | Pendente: dependem do original |
| Prancha de variantes cromáticas | assets/variantes/ | Pendente: anexo não retornado |
| Variante inspirada nas cores Ferrari | assets/variantes/ | Documentação cromática incluída; imagem original pendente |
| Paletas JSON, CSS e SVG | paletas/ | Proposta criada nesta organização |
| Diretrizes e textos | branding/, README.md | Consolidação e propostas identificadas |

Ao receber arquivos, acrescentar nome original, nome no repositório, data, origem, aprovação, formato e checksum SHA-256. Não classificar uma reconstrução como arquivo original.
