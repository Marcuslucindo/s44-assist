# Manutenção do acervo

1. Preservar cada arquivo recebido e registrar sua origem no inventário.
2. Conferir visualmente desenho, texto, transparência e cores antes de exportar.
3. Separar fontes editáveis, referências e exportações finais.
4. Atualizar README, paletas e registro de decisões quando uma definição for aprovada.
5. Revisar o conteúdo do commit para evitar arquivos temporários e dados privados.
6. Usar tags para marcos aprovados, por exemplo `v1.0.0`, somente após validar os originais.
